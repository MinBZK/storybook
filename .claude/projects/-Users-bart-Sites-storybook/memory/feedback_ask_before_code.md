Vraag altijd voordat je code gaat wijzigen.

**Why:** Gebruiker wil controle houden over wat er verandert en wil eerst meedenken over de aanpak.

**How to apply:** Bij elke codewijziging eerst de aanpak voorleggen, ook als de oplossing voor de hand lijkt te liggen. Niet direct beginnen met edits.
